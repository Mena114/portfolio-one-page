MINA MOUSA | PORTFOLIO
حزمة الاستضافة: 23 صفحة في ملف كود واحد مع مجلد صور مشترك.

فك الضغط والتشغيل
1. نزّل الأجزاء الأربعة: portfolio-part1.zip إلى portfolio-part4.zip.
2. كل جزء ZIP مستقل، وليس أرشيفاً متعدد الأجزاء. فك الأجزاء الأربعة في المجلد نفسه.
3. يجب أن يصبح index.html بجانب مجلد assets. لا تنقل الصور أو تغيّر أسماءها.
4. لعرض محلي، افتح index.html بعد فك كل الأجزاء. الخطوط الخارجية تحتاج إنترنت؛ يوجد بديل عند غيابه.
5. للاستضافة، ارفع index.html ومجلد assets بمحتوياته إلى المجلد نفسه في الاستضافة الثابتة. لا يحتاج الموقع إلى خادم تطبيقات أو قاعدة بيانات.

الملفات
- index.html: كود الموقع كله، مع التنقل بين 23 صفحة وتبديل اللغة.
- assets: 370 صورة مضغوطة بأبعادها الأصلية، ومعها 446 نسخة أصغر للشاشات المناسبة.
- CHANGES.txt: بيان تغييرات النصوص والألوان، والخطوط التي تحتاج ملفاتها الأصلية.
- QUESTIONS.txt: نقاط المحتوى غير المحسومة التي تحتاج تأكيدك قبل النشر.

التصاميم داخل الصور لم تُعدّل. لم يُنشر الموقع على استضافة مباشرة.
هذه حزمة استضافة، وليست ملف HTML مضمناً به كل الصور.

HOSTING NOTES
Extract all four independent ZIPs into one folder. Upload index.html and the complete assets folder together. No build step is needed. Google Fonts need internet; system/available fallbacks remain in place. Hash links select projects. Back/forward navigation is supported. Only the selected project is mounted, so its images load on demand. The site has not been deployed to a live host.
